# 🎓 Student Management Dashboard (P2)

An interactive **Student Management Dashboard** built using **Python, Streamlit, PostgreSQL, SQLAlchemy, Plotly, and Psycopg2** for analyzing and managing student-related data.

This dashboard provides detailed insights into student performance, attendance, subject analytics, top performers, and other academic statistics through interactive charts and filters.

---

## 🚀 Mini Project – Data Analysis & Dashboard Development

This project was developed as a **Mini Project** to practice:

- SQL Database Integration
- Data Analysis
- Dashboard Development
- Interactive Data Visualization
- Backend + Frontend Integration

---

## ✨ Features

- 📊 Interactive Student Analytics Dashboard
- 🎯 Subject-wise Performance Analysis
- 🧑‍🎓 Student Records Monitoring
- 📈 Attendance Analytics
- 🏆 Top Performer Tracking
- 🔍 Multiple Dynamic Filters
- ⚡ Real-time SQL Data Fetching
- 🌐 Streamlit Web UI

---

## 🗄️ Database & Data Generation

The project uses a **Cloud PostgreSQL Database** from **Neon Console** to store student records.

### Technologies Used for Database:

- PostgreSQL
- SQLAlchemy
- Psycopg2

### Fake Data Generation:

Student records were generated using the **Faker** library for testing and analytics purposes.

---

## 📊 Dashboard Functionalities

The dashboard allows users to:

- Filter students by different categories
- Analyze marks and attendance
- View top-performing students
- Monitor pass percentages
- Compare subject-wise averages
- Explore insights using interactive charts
